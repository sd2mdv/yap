КУРС «ЯЗЫКИ ПРОГРАММИРОВАНИЯ» — ЛОКАЛЬНЫЙ СЕРВЕР
================================================

Что в папке
  index.html          — весь курс: слайды, портал студента, портал преподавателя
  server.py           — сервер: раздаёт курс по Wi-Fi и сохраняет результаты в текстовые файлы
  start-mac.command   — запуск двойным щелчком на macOS
  start-windows.bat   — запуск двойным щелчком на Windows (нужен Python 3: python.org)
  data/               — появится после первого запуска: результаты студентов

Как провести занятие
  1. Подключите ноутбук к Wi-Fi аудитории (или раздайте Wi-Fi с ноутбука / телефона).
  2. Запустите сервер: двойной щелчок по start-mac.command или start-windows.bat
     (или в терминале: python3 server.py).
  3. В окне сервера появятся адрес для студентов (например http://192.168.1.25:8000/)
     и КЛЮЧ ПРЕПОДАВАТЕЛЯ.
  4. Откройте этот адрес в браузере на ноутбуке и выводите лекцию на проектор.
     QR-коды на слайдах автоматически ведут на ваш сервер.
  5. Студенты сканируют QR, вводят ФИО и группу — это отметка о присутствии.
     Ответы на кейсы, практические и лабораторные сохраняются на вашем ноутбуке.
  6. Портал преподавателя (кнопка на главной) → ключ из окна сервера:
     посещаемость, правильность ответов, ведомость за семестр, проверка работ,
     печать и выгрузка в Excel (CSV).

Где лежат результаты (обычные текстовые файлы, по строке на событие)
  data/events.jsonl    — присутствие, ответы, сданные работы (с кодом лабораторных)
  data/grades.jsonl    — ваши оценки и комментарии
  data/teacher_key.txt — ключ входа (можно поменять: python3 server.py --key НОВЫЙ)
  Делайте копию папки data/ после занятий. Файлы можно открыть в портале
  преподавателя и без сервера: «Портал преподавателя» → выбрать файлы.

Важно
  - Если студенты не могут открыть адрес: проверьте, что ноутбук и телефоны в одной
    сети, и разрешите Python входящие подключения (брандмауэр macOS/Windows).
    В некоторых университетских сетях устройства изолированы друг от друга —
    тогда раздайте Wi-Fi с ноутбука или телефона.
  - Лабораторные на JavaScript работают без интернета. Python и PHP загружаются
    в браузер студента из интернета (≈5–10 МБ при первом запуске).
  - Код студентов выполняется только в их браузерах, на вашем ноутбуке — нет.
  - Персональные данные студентов (ФИО, группа) хранятся только на вашем ноутбуке.
